# 从 SuperAgent 到小白可用的 Personal Agent：我改了它的代码，已开源

> 小红书稿 · 2026-11-01
>
> 仓库：https://github.com/hxh230802/dsh-superagent-prototype

---

DeepSeek 开源了 Super-agent 原型。

多任务调度做得极好——但它只有两个洞：

**只能听 GitHub，而且根本不长记性。**

我把这两块补上了，代码已经开源。

---

## 一、让它能听见你自己的电脑

原版的感知是**轮询**：每隔一会儿去问 GitHub 有没有新东西。

但你自己电脑上的截图工具、下载文件夹、剪贴板——它们不会等 AI 来问。

所以我接了一个本机协议（MSP）：软件有变化就**推**一条信号，零配置，不用注册回调、不用续期、不用暴露端口。

**AI 从「去问」变成「被通知」。**

---

## 二、让它长记性

原版仓库里 `grep -ri experience` —— **零结果**。

我加了经验库：一条经验一个 `.md`，写成「**当…就…因为…**」。

```
当 file.**  就 不安装，先问这个人  因为 装错了不可逆
```

命中才注入，**没命中的一个字都不进提示词**。所以经验越攒越多，提示词不会越来越长。

---

## 三、它真的会干活（磁盘为证）

```
Invoice.pdf  →  archive/pdf/2026-11-01-Invoice.pdf
notes.md     →  archive/md/2026-11-01-notes.md

WeChatSetup.exe  →  原地未动，没装
```

---

## 四、最扎心的发现

它拒绝安装时给的理由是：

> **"The MSP source has no reply channel and no human actor"**

翻译过来：**它想问我，但没有嘴。**

「先问后做」这个策略，在无人称信号上根本执行不了。
这不是模型不够强，是**架构缺了一层**——主动性需要一个「收件人」。

---

## 五、关于先后

据我们所知，**这是最早把「本机推送感知 + 经验库」一起接进 Super-agent 的公开实现之一。**

同类工作如果更早、更好，欢迎在 issue 里指出来——我们改，并且注明出处。

---

## 六、说清楚：现在还不是"小白可用"

这是**目标**，不是现状。

今天要装它，还得开 WSL、对齐 dsh 版本、补一个必填的 `stateDir`——每一步都能劝退一个人。

所以接下来最想做的事，不是加功能，是**把这条安装路径压到三步以内**。


---

## 七、它能跑在 Windows 上（实测）

不用 WSL。

原版的服务脚本其实早就有 Windows 分支（`msvcrt` 文件锁、`kernel32` 查进程、隐藏控制台代替 tmux），
只是一直没人验证过。我跑通了：

```
pids: [66812]
dsh web: http://127.0.0.1:3080/?token=...
```

据我们所知，**这是第一个在 Windows 上原生跑起来的 dsh-superagent fork。**

唯一的坑：别和 WSL 里的实例同时开——WSL 的端口转发会占住 3080，而 `Get-NetTCPConnection` 看不见它。

---

## 八、我踩的四个坑（都记在 README 里）

1. 用 `bash` 跑一个 Python 脚本 + CRLF 换行 → 误判成"只能在 Linux 跑"
2. 拿错 URL 测了五次 404，然后据此改了四次配置
3. `catch(() => undefined)` 把真错误吞了，查了半天"信号为什么没进"
4. A/B 实验两次被污染：一次文件根本不存存，一次提示词里已经写了同样的规则

**这些不是卖点，是门槛。写出来，别人能少走一遍。**

## 九、号召：别各做各的

主动式 Agent 现在最大的问题不是模型，是**碎片化**：

- 有人做记忆，有人做感知，有人做经验，各写各的
- 每个人都在重复造「轮询 vs 推送」这个轮子

所以：

🍴 **Fork 它。** 基于官方原型，能同步上游，不会变成孤儿分支。
🐛 **提 issue。** 特别是"你这个实验设计有错"——今天我自己就犯了三次。
📄 **带数据来。** 空口说"我的更好"没意义，磁盘和日志才作数。
🔁 **别私藏。** 你踩的坑，别人明天还会踩一遍。
